# Data acquisition (Step 1) — 2026-10-14

Terminology (see CLAUDE.md): "dict 0-5000" / "dict 5000-6500" = MUSE dictionaries (Conneau et al. call them train / test); "GW vocabulary" = top-K words fed to GW; "candidates" = target words searched at retrieval.

## Embeddings
- Source: `https://dl.fbaipublicfiles.com/fasttext/vectors-wiki/wiki.{lang}.vec` (all six URLs alive, HTTP 200)
- Took the first 200,001 lines (header + top 200k words) with `curl ... | head -n 200001`
- Location: `data/raw/MUSE/wiki.{en,es,fr,de,it,ru}.vec` (~500 MB each, 3.0 GB total; gitignored)
- Header line keeps the ORIGINAL vocab size (e.g. `2519370 300` for en), not 200000 — loaders must not trust it as a line count
- Parsed with `localgw.data.load_vectors`: 200,000 words × 300 dims for every language, 0 malformed lines, 0 duplicates

## Dictionaries
- Source: `https://dl.fbaipublicfiles.com/arrival/dictionaries/{src}-{trg}{,.0-5000,.5000-6500}.txt`
  (fetched directly instead of MUSE `get_evaluation.sh`, which also pulls large monolingual eval data)
- Pairs: en↔{es,fr,de,it,ru}, full / dict 0-5000 / dict 5000-6500
- Location: `data/raw/MUSE/crosslingual/dictionaries/` (matches otalign's default `--data_dir data/raw` layout)

## Coverage (`analysis/tables/dictionary_coverage.{csv,md}`)
Generated by `code/experiments/dictionary_coverage.py`.

Key findings:
- **The dictionaries are split by source-word frequency rank.** en-es: dict 0-5000 source words have en ranks 2–5473,
  dict 5000-6500 source words 5474–7136. So with K ≤ 5000 *no* dict 5000-6500 word is inside the GW vocabulary, and with K=10000 only ~66% (en-es).
  → P@1 on dict 5000-6500 (the MUSE standard) can only be measured after extending the map to the full 200k vocab
  (otalign does this via Procrustes). P@1 from Γ's argmax on the GW vocabulary alone is only measurable on dict 0-5000.
  This may also be why otalign hard-codes `dict_fold = 'train'`.
- With 200k words, coverage is 100% for every pair and fold.
- One-to-many is common: en-es dict 5000-6500 has 1.98 translations per source word on average, 56% have >1.
- en-ru is the hardest: at K=20000 only 57% of en-ru dict 5000-6500 words have a gold translation in the ru top-20000.
