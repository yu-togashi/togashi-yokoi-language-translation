# Accumulated Agent Feedback

This file is the **canonical, versioned source** of agent guidance accumulated
from PI-student meetings. Every `/meeting` invocation appends new bullets
here. Agents read this file alongside `CLAUDE.md` to decide how to do their
work.

## Format

Each entry is dated and tagged with the transcript it came from, so the
provenance is clear and old guidance can be retired when it no longer applies.

```
## YYYY-MM-DD  (source: meetings/summaries/YYYY-MM-DD_slug.md)

- Feedback bullet 1
- Feedback bullet 2
- ...
```
